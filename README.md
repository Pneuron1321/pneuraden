# PNEURADEN

Веб-приложение «компас · навигация». Две версии, без сборки, стартовая точка — Ровинь:

- **Лайт** (`index.html`, открывается по умолчанию) — радар, навигация пешком и на машине,
  камеры скорости в радиусе 21 км и по маршруту, голосовые подсказки. ~70 КБ, без 3D.
- **Полная** (`full.html`) — всё остальное: ивенты, AR, космос, «Пульс времени», Режиссёр.

Между ними — кнопки «⭐ ПОЛНАЯ» (в Лайте) и «🎮 Лайт» (на главном экране полной).

## Структура

| Путь | Что это |
|------|---------|
| `index.html` + `lite.js` | **Лайт** — версия по умолчанию |
| `full.html` | Полная версия |
| `manifest.webmanifest`, `sw.js`, `assets/icon-*.png` | Установка на телефон как приложение, быстрый старт и работа без сети |
| `proto-globe.html` | Прототип «Один мир»: глобус MapLibre, экраны заменены высотой камеры (улица → орбита) |
| `assets/tunnel.jpg` | Фоновая текстура «туннель» для главного экрана |
| `archive/` | Прошлые версии (v1.2, v1.7a-резерв, v3.4) — только для истории |
| `firebase/database.rules.json` | Правила доступа к общей базе (кто что читает и пишет) |
| `firebase/rules.test.mjs` | Проверка правил на эмуляторе (38 случаев, включая попытки атак) |
| `modes/` | Тексты «когнитивных режимов» (к коду не относятся) |

## Лайт: как пользоваться

1. **«НАЖМИ, ЧТОБЫ НАЧАТЬ»** — одно касание включает звук, компас (iOS спрашивает разрешение) и GPS.
2. **Радар** — круглая миникарта, крутится по курсу. Камеры — жёлтые значки, на маршруте — оранжевые;
   то, что за краем (камера впереди, финиш), — указатель по кромке с расстоянием.
   Снизу — знак ограничения (лимит камеры впереди, иначе лимит дороги из OSM) и спидометр.
3. **Тап по радару** → карта. Тапни по карте или найди место → выбери **🚗 Ехать** или **🚶 Идти** →
   видно длину, время, прибытие и сколько камер на пути → **▶ ПОЕХАЛИ!**
4. В пути: зелёная плашка — следующий манёвр (тап — повторить голосом), голос по-русски
   за 800/300/60 м (пешком — 90/20 м), сход с маршрута — автоматическое перестроение,
   экран не гаснет. Маршрут переживает перезагрузку страницы (6 часов).
5. **Камеры**: за 600 м баннер и голос, с 400 м — сигналы как у парктроника,
   превышение — красная тревога; проехал честно — «монетка». Кнопка 📸 выключает.
6. **ФИНИШ!** — итоги поездки и звёзды за езду без превышений.

Сервисы Лайта (все бесплатные, без ключей): тайлы OpenStreetMap (тёмный вид — CSS-фильтром),
OSRM (машина), FOSSGIS `routing.openstreetmap.de` (пешком), Overpass (камеры, лимиты),
Nominatim/Photon (поиск). Предупреждения о камерах разрешены не везде (например, в Германии
и Швейцарии — запрещены за рулём).

## Полная версия: экраны

- **Радар** — компас, «Пульс времени» (релятивистская поправка gh/c² − v²/2c²),
  пройденный путь, «Небо в разрезе».
- **Карта** (Leaflet) — слои: ивенты, клуб, пользователи, камеры, самолёты,
  молнии, пробки, спутники; поиск места, маршрут, навигация.
- **Навести (AR)** — камера + метки мест, самолётов, спутников и звёзд.
- **Космос** (three.js) — Земля, МКС в реальном времени, антипод.
- **Ивенты / Профиль / Админ** — добавление ивентов и их верификация.

## Внешние сервисы

Leaflet, three.js, satellite.js (CDN) · Firebase Realtime DB (позиции

## Запуск

Нужен любой статический HTTP-сервер (фоновая текстура грузится отдельным
файлом, и WebGL не примет её при открытии через `file://`):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Геолокация, компас и камера в браузере работают только по HTTPS или на `localhost`.

## Общий мир: Firebase (сейчас ВЫКЛЮЧЕН)

Сейчас в `full.html` стоит `const FB_ON=false;` — Firebase не грузится вовсе, профиль (имя и цвет)
и ивенты хранятся только на телефоне, админки и следов нет. Код общего мира готов и проверен;
чтобы включить, поставь `FB_ON=true` и один раз сделай три шага ниже — без них вход по email
не заработает, а база останется открытой всем.

Аккаунты, ивенты, статус клуба и «Следы города» живут в Firebase (проект `pneuron-app`).

1. **Вход.** Firebase Console → Authentication → Sign-in method → включить
   **Email/Password** и **Anonymous** (гости читают ивенты анонимно).
2. **Правила.** Realtime Database → Rules → вставить содержимое
   `firebase/database.rules.json` → Publish.
3. **Админ.** Зарегистрироваться в приложении → Профиль → «ID аккаунта» → копировать.
   Затем Realtime Database → Data → добавить узел `admins` → ключ = этот ID, значение `true`.
   Перезапустить приложение — появится «⚡ Панель администратора».

Что где лежит в базе:

| Путь | Кто читает | Кто пишет |
|------|-----------|-----------|
| `events/<id>` | все (и гости) | автор — создать на проверку и отозвать, пока не проверен; админ — всё |
| `eventMsgs/<id>` | только админы | автор ивента (одно сообщение) |
| `club` | все | админ |
| `profiles/<uid>` | вошедшие | владелец |
| `users/<uid>` | вошедшие | владелец; точка огрублена до ~1 км, исчезает при выходе |
| `trails/<день>/<клетка>/<хеш>` | вошедшие | вошедшие (без перезаписи); админ чистит старые дни |
| `admins/<uid>` | только сам uid | только из консоли |

**Следы города** включаются в профиле, по умолчанию выключены. Клетка ~150 м, запись только
в движении, ключ — хеш (uid + день + клетка), поэтому клетки одного человека не связать в путь;
клетка видна, если за день через неё прошли минимум двое. Админский клиент удаляет дни старше вчерашнего.

Проверить правила после правки (нужны Node и Java):

```bash
npm i -D firebase-tools @firebase/rules-unit-testing firebase
npx firebase emulators:exec --only database --project demo-pnd "node firebase/rules.test.mjs"
```
